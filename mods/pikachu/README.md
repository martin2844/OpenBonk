# Pikachu mod (experimental)

This API 3 example adds Pikachu with Thunderbolt. The Lua callback in [`content/main.lua`](content/main.lua) alternates the host weapon's damage multiplier; the manifest produced by [`build_test_package.py`](build_test_package.py) defines the character, animations, weapon and the passive: +1% power-up drop chance and +1% duration per level gained.

Download [Pikachu-mod.zip](https://github.com/martin2844/OpenBonk/releases/download/v0.1.0-beta/Pikachu-mod.zip) and copy it to Android. In the OpenBonk launcher select **Import mod**, choose the ZIP, then enable it in **Manage mods**. Start a run and select Pikachu. The mod is separate from the APK, and support can vary between builds. The included package was imported and enabled on iPlay with an isolated variant of the beta; Pikachu appeared in the selection screen and entered Forest. This was not a complete run.

To rebuild the ZIP with the included Android model bundle and art, run `python3 mods/pikachu/build_test_package.py` from the repository root. It creates `mods/pikachu/pikachu-mod.zip` without replacing an existing file; use `--output /path/to/new.zip` for another location. Its contents match the included local test package and are reproducible. The builder uses `study/android-bundle/pikachu-model` and the assets in `content/`.

The model bundle can also be rebuilt from a separately obtained `PikachuAnim.fbx`, Blender and Unity 2023.2.22f1 with Android build support. The source FBX is not included in this repository. From the repository root:

```sh
python3 mods/pikachu/build_from_source.py \
  --source-fbx /path/to/PikachuAnim.fbx \
  --blender /path/to/blender \
  --unity /path/to/Unity/Editor/Unity \
  --output /path/to/new-local-build-directory
```

The output directory must not exist. The command creates an isolated Blender workspace and Unity project there, generates the movement clips and surfboard, and checks the finished Android bundle for its model, five clips, surfboard and audio before packaging `pikachu-mod.zip`. It retains logs and intermediate files in that directory. Blender 5.1.1 and Unity 2023.2.22f1 were used in a local Linux test with a source FBX whose SHA-256 is `fce0604ecdff63819abfcf03b11818bad31dee8a630cb1a225f9fc857d5aedf3`; systems needing a Unity wrapper can add `--runner steam-run`. The generated bundle differs byte-for-byte from the included bundle. The portrait and weapon icon are the checked-in assets, rather than freshly rendered by this command. Generated files contain third-party character data and must be treated according to their provenance.

A ZIP generated by this source workflow was imported into the private `970e9bb` research APK on an Android 15 x86-64 emulator with ARM64 translation. Pikachu appeared with the expected colors, entered Forest, moved and defeated enemies, reached level 1, upgraded Thunderbolt and resumed combat; the displayed duration and power-up drop chance were both 1.01× at level 1. This short test did not verify audio playback, every animation, physical controls or long-run behavior.

The locally rebuilt ZIP was also imported and enabled through the launcher in the private `970e9bb` research build on an Android 15 x86-64 emulator with ARM64 translation. Pikachu appeared in character selection with Thunderbolt and its passive description, entered Forest, moved, defeated enemies and reached level 1. The stats screen showed 1.01× duration and 1.01× power-up drop chance. The emulator exited during the first attempt to enter Forest; a second attempt succeeded, and the cause of the first exit is unknown. This short test did not establish audio, every animation, long-run behavior or physical-controller operation.

The checked-in package builder's output was also imported and enabled in a private clean-build APK from `96abedd` on the same class of emulator. Pikachu entered Forest, defeated enemies and upgraded Thunderbolt; duration and power-up drop chance displayed 1.01× at level 1 and 1.02× at level 2. This short check did not measure the alternating Lua damage callback, audio, every animation, physical controls or long-run behavior.

The package builder was also tested with the private `502b0ea` fresh-clone dual APK using the experimental relocated fonts and Windows game-data ZIP. In an Android 15 x86-64 emulator with ARM64 translation, Pikachu entered Forest, moved, defeated enemies, reached level 1 and resumed after choosing an upgrade; duration and power-up drop chance both displayed 1.01×. This short test did not establish native-device, audio, animation, Lua damage-callback or long-run behavior.
