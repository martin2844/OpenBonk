# Pikachu mod (experimental)

This API 3 example adds Pikachu with Thunderbolt. The Lua callback in [`content/main.lua`](content/main.lua) alternates the host weapon's damage multiplier; the manifest produced by [`build_test_package.py`](build_test_package.py) defines the character, animations, weapon and the passive: +1% power-up drop chance and +1% duration per level gained.

Download [Pikachu-mod.zip](https://github.com/martin2844/OpenBonk/releases/download/v0.1.0-beta/Pikachu-mod.zip) and copy it to Android. In the OpenBonk launcher select **Import mod**, choose the ZIP, then enable it in **Manage mods**. Start a run and select Pikachu. The mod is separate from the APK, and support can vary between builds. The included package was imported and enabled on iPlay with an isolated variant of the beta; Pikachu appeared in the selection screen and entered Forest. This was not a complete run.

To rebuild the ZIP with the included Android model bundle and art, run `python3 mods/pikachu/build_test_package.py` from the repository root. It creates `mods/pikachu/pikachu-mod.zip` without replacing an existing file; use `--output /path/to/new.zip` for another location. Its contents match the included local test package and are reproducible. The Blender authoring scripts are included, but the external source FBX is not; regenerating the model bundle from scratch is not yet a documented clean build. The builder uses `study/android-bundle/pikachu-model` and the assets in `content/`.

The original model is [Pikachu by HarrisonHag1](https://sketchfab.com/3d-models/pikachu-273766237c614ab1bbaf094c9fc72a3e), marked CC BY 4.0 by its uploader. The local source FBX was obtained from [mzschwartz5/stylized-toon-shader](https://github.com/mzschwartz5/stylized-toon-shader); that repository credits the model and says it was animated in Blender. The source animation's separate license was not established. The OpenBonk movement actions are authored for the existing rig. The uploader's license label does not establish rights to the Pokémon character, which belongs to its respective rights holders. The mod is an unofficial fan example and its provenance and redistribution rights need independent review.
