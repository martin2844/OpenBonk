# Healing Heart: example item mod

This API 3 example adds an item to the normal item pool. Once per game second,
while the player is alive and below half health, it requests healing of 2 per
stack, capped at 100 per callback. Existing healing modifiers and game rules
still apply. The code checks a copied player state and cannot write it directly.

From the project root, run `python3 mods/example-healing-item/build.py`, copy the
resulting `example-healing-item.zip` to Android, import it in the OpenBonk
launcher and enable it under Manage Mods. The builder refuses to overwrite an
existing ZIP; move or remove an old build before rebuilding after edits.

The icon is generated by the builder and uses no game assets. This requires a
build with item tick context support; older installed APKs lack it. The API is
experimental and does not support arbitrary game modification or untrusted-code
isolation. This example is independent of the Pikachu mod and does not make the
game APK or its bundled assets distributable.
