# Item Lab (experimental)

An independently written menu inspired by [ItemSpawner by AutoBans](https://thunderstore.io/c/megabonk/p/AutoBans/ItemSpawner/) and [ItemGiver by anro](https://thunderstore.io/c/megabonk/p/anro/ItemGiver/). No upstream license was identified for either package; this implementation contains no original mod code, art or binaries.

When enabled, open the pause menu and select **Items**. Search by item name, choose a rarity or browse pages, select an item and add 1, 5, 10 or 50. **+1 filtered** adds one of each item matching the current search and rarity filter. Each action is limited to 50 per individual item and 999 total copies of one item. The game may reject items under a challenge's normal restrictions; the menu reports how many were actually added. If an item effect fails midway, the game may already have applied part of the action, and the result reports the amount observed rather than pretending to undo arbitrary effects.

Items are granted through the game's normal inventory method and preserve its ordinary item effects and events. **Those events can change achievements, statistics or other progression during the run.** Merely opening and closing the menu does not grant an item. The menu is available only while a run is paused; disable the package and restart to hide it. This is an independent combined adaptation: its layout and controls differ from the PC mods, and full behavioral equivalence is not established.

The package needs a future APK that supports the `item_lab` hook; beta 0.1.4 cannot import or run it. It is not in the public catalog. A Unity Editor test covers invalid requests, per-action and per-item bounds, normal item events, challenge restrictions and partial failure. An isolated Android diagnostic build tested searching, rarity filtering, a filtered bulk grant, quantities, disabled behavior and returning to the pause menu. Android D-pad key events were simulated for menu navigation; physical-controller behavior and the final integrated launcher import remain untested.
