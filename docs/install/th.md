# คู่มือการติดตั้ง OpenBonk เบต้า

> เครื่องแปลจากภาษาอังกฤษ กรุณารายงานคำแนะนำที่ไม่ชัดเจน

> OpenBonk เป็นพอร์ตชุมชนที่ไม่เป็นทางการในการทดสอบ ผู้ทดสอบแต่ละคนต้องการสำเนา Steam ของ Megabonk ที่เข้ากันได้เป็นของตัวเอง

## สิ่งที่คุณต้องการ

- อุปกรณ์ Android 64 บิตที่ใช้ Android 8 หรือใหม่กว่า เบต้าได้รับการทดสอบบน Retroid Pocket 5 และ iPlay 70 mini Pro ที่ใช้ Android 15; ยังไม่มีการสร้างความเข้ากันได้กับอุปกรณ์อื่น
- การติดตั้ง Steam ของ Megabonk ที่เข้ากันได้ของคุณเองบนคอมพิวเตอร์ ตัวเรียกใช้งานจะตรวจสอบไฟล์ที่รองรับโดยเฉพาะ การอัปเดตเกมอื่นอาจเข้ากันไม่ได้
- พื้นที่ว่างพิเศษสำหรับไฟล์ ZIP ข้อมูลการเตรียมการ และข้อมูลเกม ข้อกำหนดจะแตกต่างกันไปตามอุปกรณ์ การเตรียมการอาจใช้เวลาหลายนาที (ประมาณสี่นาทีในการทดสอบ iPlay 70 mini Pro หนึ่งครั้ง)
- `OpenBonk.apk` ในแพ็คเกจเบต้า สำรองข้อมูลความคืบหน้าการทดสอบที่มีอยู่ก่อนที่จะเปลี่ยนการติดตั้ง APK ที่ได้รับการลงนามเป็นอย่างอื่นอาจต้องมีการติดตั้งแยกต่างหาก

## รับแพ็คเกจเบต้า

ดาวน์โหลด `OpenBonk-beta.zip` จาก [รุ่นเบต้า](https://github.com/martin2844/OpenBonk/releases/tag/v0.1.1-beta) และแตกไฟล์ลงในคอมพิวเตอร์ของคุณ ประกอบด้วย `OpenBonk.apk` คู่มือการติดตั้ง และโฟลเดอร์ `tools` เก็บโฟลเดอร์ `tools` ทั้งหมดไว้ หากคุณต้องการตัวช่วย ZIP APK เป็นตัวติดตั้ง คุณต้องสร้าง ZIP ส่วนตัวแยกต่างหากจากสำเนา Steam ของคุณเอง

## สร้าง ZIP ข้อมูลเกม

1. ใน Steam ให้เปิดคุณสมบัติของ Megabonk แล้วเลือก **ไฟล์ที่ติดตั้ง → เรียกดู**
2. ค้นหาโฟลเดอร์ `Megabonk_Data` บน Windows คลิกขวาแล้วเลือก **ส่งไปที่ → โฟลเดอร์บีบอัด (ซิป)**; บน Windows 11 อาจอยู่ภายใต้ **แสดงตัวเลือกเพิ่มเติม** บน Linux ให้ใช้ตัวเลือกการบีบอัดของตัวจัดการไฟล์แล้วเลือก ZIP บีบอัดทั้งโฟลเดอร์ ไม่ใช่แค่เนื้อหาเท่านั้น แต่ ZIP ควรมีโฟลเดอร์ `Megabonk_Data` พร้อมด้วยโฟลเดอร์ย่อย [Microsoft: zip และแตกไฟล์ zip](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/zip-and-unzip-files)
3. ตรวจสอบให้แน่ใจว่า ZIP ไม่ใหญ่กว่า **1 GiB** เชื่อมต่อและปลดล็อคอุปกรณ์ Android ของคุณ เลือก **การถ่ายโอนไฟล์** ในการแจ้งเตือน USB และคัดลอกทั้ง Steam ZIP และ `OpenBonk.apk` ของเบต้าไปยังดาวน์โหลด รักษา Steam ZIP ให้เป็นส่วนตัว: ประกอบด้วยไฟล์จากสำเนาเกมของคุณ [Android: ถ่ายโอนไฟล์ด้วย USB](https://support.google.com/android/answer/9064445?hl=en)

ZIP การติดตั้ง Linux แบบเต็มได้รับการทดสอบบน Retroid และ iPlay ZIP ขนาดเล็กที่มีไฟล์ Windows ที่รองรับ 39 ไฟล์ก็ถูกนำเข้าบน iPlay และไปถึง Forest การเตรียม ZIP บนพีซี Windows จริงและการนำเข้าโฟลเดอร์การติดตั้ง Windows แบบเต็มยังไม่ได้รับการตรวจสอบ

หาก ZIP แบบเต็มเกิน 1 GiB โฟลเดอร์ `tools` ของแพ็คเกจจะมีตัวช่วยที่จะตรวจสอบไฟล์ที่จำเป็น 39 ไฟล์และสร้าง ZIP ที่เล็กลง บน Windows ให้เปิด PowerShell ในโฟลเดอร์ที่มี `tools` และรันคำสั่งนี้ โดยแทนที่พาธแรกด้วยโฟลเดอร์เกมของคุณ:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\create-launcher-steam-zip.ps1 "C:\ruta\a\Megabonk\Megabonk_Data" "$env:USERPROFILE\Desktop\OpenBonk-Steam.zip"
```

บน Linux จากโฟลเดอร์เดียวกันและด้วย Python 3.9 หรือใหม่กว่า:

```sh
python3 tools/create-launcher-steam-zip.py "/ruta/a/Megabonk/Megabonk_Data" "$HOME/OpenBonk-Steam.zip"
```

บน Windows หากติดตั้ง Python 3.9 หรือใหม่กว่า คุณยังสามารถเรียกใช้ตัวช่วย Python จาก PowerShell ได้:

```powershell
py -3 .\tools\create-launcher-steam-zip.py "C:\ruta\a\Megabonk\Megabonk_Data" "$env:USERPROFILE\Desktop\OpenBonk-Steam.zip"
```

คัดลอก ZIP ของตัวช่วยไปที่ Downloads บน Android และเลือกแทน ZIP แบบเต็ม ตัวช่วยจะไม่เขียนทับ ZIP ที่มีอยู่และปฏิเสธเวอร์ชันของไฟล์ที่ไม่รู้จัก ตัวช่วย Python ทำงานโดยใช้ Windows Python ภายใต้ Wine และ ZIP ของมันถูกนำเข้าบน iPlay ตัวช่วย PowerShell ได้รับการทดสอบกับ PowerShell 7 บน Linux ไม่มีการทดสอบตัวช่วยใดบนพีซี Windows ดั้งเดิม

## ติดตั้งและเล่น

1. เปิด `OpenBonk.apk` ในตัวจัดการไฟล์ของ Android หากคุณดูรายละเอียดไฟล์ ให้มองหา **เปิดด้วย → ตัวติดตั้งแพ็คเกจ** หาก Android ขออนุญาตติดตั้งจากแอปนั้น ให้อ่านข้อความแจ้งและปฏิบัติตามคำแนะนำ คุณสามารถปิดการอนุญาตนั้นได้ในภายหลัง
2. เปิด OpenBonk ในตัวเรียกใช้งาน ให้เลือก **Controller** หรือ **Touch**
3. เลือก **Megabonk game files ZIP** ค้นหา ZIP ใน Downloads และเลือก **Import prepared Android data** มีไว้สำหรับชุด Android ที่เตรียมไว้ก่อนหน้านี้ ไม่ใช่ Steam ZIP เปิดแอปไว้และรอ **Data ready** ข้อความเปลี่ยนแปลงระหว่างขั้นตอน แต่ไม่มีการแสดงเปอร์เซ็นต์
4. เลือก **Play** ในการเปิดตัวครั้งแรก ข้อความและพื้นผิวจะถูกนำเข้าก่อนที่เมนูเกมจะปรากฏขึ้น

## นำเข้าและสำรองข้อมูลความคืบหน้า

การนำเข้าโปรไฟล์ Steam เป็นทางเลือก ขั้นแรกให้ปิดเกมบนคอมพิวเตอร์ของคุณและสำรองข้อมูลไว้ ค้นหาโฟลเดอร์บัญชีที่ `~/.config/unity3d/Ved/Megabonk/Saves/CloudDir/` บน Linux หรือลองใช้ `%USERPROFILE%\AppData\LocalLow\Ved\Megabonk\Saves\CloudDir\` บน Windows (เส้นทาง Windows ยังไม่ได้รับการยืนยัน) ZIP `progression.json` และ `stats.json` จากบัญชีเดียวกันเข้าด้วยกัน คัดลอก ZIP ไปยัง Android แล้วเลือก **Import profile ZIP** การเริ่มเกมจะแทนที่ความคืบหน้าของบัญชี Android ปัจจุบัน ดังนั้นให้เก็บข้อมูลสำรองเดิมไว้ นี่เป็นการนำเข้าเพียงครั้งเดียว ไม่ใช่การซิงโครไนซ์ระหว่างพีซีกับ Android ZIP โปรไฟล์เป็นแบบส่วนตัว อย่าแนบไปกับรายงาน

หากต้องการสำรองข้อมูลความคืบหน้าของ Android ให้ปิดเกมโดยสมบูรณ์ เปิดตัวเรียกใช้งาน และเลือก **Export profile** เลือกโปรไฟล์และบันทึก ZIP ไว้ในที่ส่วนตัว คุณสามารถกู้คืนได้โดยใช้ **Import profile ZIP** ZIP มีความคืบหน้าและสถิติ แต่ไม่มีการควบคุมหรือม็อด ส่งออกได้รับการทดสอบบน iPlay พร้อมโปรไฟล์ทดสอบ เก็บข้อมูลสำรอง Steam ดั้งเดิมไว้เช่นกัน

**การสำรองข้อมูล Android:** เวอร์ชันนี้ไม่ได้ปิดใช้งานการสำรองข้อมูลอัตโนมัติ Android อาจรวมข้อมูลแอป เช่น การบันทึกหรือการนำเข้าโปรไฟล์ที่รอดำเนินการ ไว้ในการสำรองข้อมูลบัญชีและการถ่ายโอนอุปกรณ์ ทั้งนี้ขึ้นอยู่กับการตั้งค่าอุปกรณ์ ตัวเปิดเกมใช้อินเทอร์เน็ตสำหรับการอัปเดตและแค็ตตาล็อกม็อด ตรวจสอบการตั้งค่าการสำรองข้อมูลของ Android หากคุณไม่ต้องการสิ่งนี้ การถอนการติดตั้งแอปสามารถลบข้อมูลในเครื่องได้ สำรองความคืบหน้าก่อน [การสำรองข้อมูลอัตโนมัติของ Android](https://developer.android.com/identity/data/autobackup)

## การแก้ไขปัญหา

- ** ZIP ที่เข้ากันไม่ได้: ** เลือก `Megabonk_Data` จากการติดตั้งเสร็จสมบูรณ์และเวอร์ชันเกมที่รองรับ การอัปเดต Steam อาจเปลี่ยนแปลงไฟล์ที่ตรวจสอบโดยตัวเรียกใช้งาน
- **พื้นที่ไม่เพียงพอ:** เพิ่มพื้นที่ว่างแล้วลองอีกครั้ง ตัวเรียกใช้งานยังไม่ได้คำนวณความต้องการพื้นที่ทั้งหมดล่วงหน้า
- **การนำเข้าข้อความล้มเหลวเมื่อเปิดตัว:** เปิดเกมอีกครั้งเพื่อลองอีกครั้งในขณะที่ไฟล์ ZIP ที่ค้างอยู่ยังคงแคชอยู่ หาก Android ล้างแคชแล้ว ให้เลือก ZIP อีกครั้ง
- **APK จะไม่ติดตั้งบนเวอร์ชันอื่น:** ลายเซ็นหรือรหัสแอปพลิเคชันอาจแตกต่างกัน สำรองข้อมูลความคืบหน้าที่คุณต้องการเก็บไว้ก่อนถอนการติดตั้งแอปที่มีอยู่
- **Play Protect ขอให้สแกน APK:** บน iPlay หนึ่งเครื่อง Android เสนอให้ส่งไฟล์ไปยัง Google เพื่อทำการวิเคราะห์ก่อนการติดตั้ง อ่านข้อความแจ้งและตัดสินใจว่าจะส่งหรือไม่ ผลลัพธ์ของการสแกนและการติดตั้งเสร็จสมบูรณ์ผ่านตัวติดตั้งระบบยังไม่ได้รับการตรวจสอบ

## รายงานปัญหา

รวมถึงรุ่นอุปกรณ์ เวอร์ชัน Android ไม่ว่าคุณจะใช้คอนโทรลเลอร์หรือระบบสัมผัส ขั้นตอนที่ทำ สิ่งที่คุณคาดหวัง และสิ่งที่เกิดขึ้น แนบภาพหน้าจอแสดงข้อผิดพลาดหากมีประโยชน์ อย่ารวม Steam ZIP โปรไฟล์ หรือข้อมูลบัญชีของคุณไว้ในรายงานทั่วไป
